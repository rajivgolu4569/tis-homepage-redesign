# TIS Homepage Redesign

A responsive homepage redesign for Tulas International School, built using React and Vite.

## Features

* Responsive homepage for desktop, tablet and mobile
* Modular React components
* Scroll animations
* Custom cursor and scroll progress indicator (where supported)
* Interactive navigation

## Tech Stack

* React
* Vite
* JavaScript
* CSS / Tailwind CSS (as used in the project)
* Framer Motion

## Getting Started

### Prerequisites

* Node.js
* npm

### Installation

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/tis-homepage-redesign.git
```

Move into the project directory:

```bash
cd tis-homepage-redesign
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

### Build

```bash
npm run build
```

### Lint

```bash
npm run lint
```
